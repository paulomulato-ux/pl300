📌 Resumo – Preparar Dados para Power BI

📌 Summary – Preparing Data for Power BI

Este módulo aborda como conectar, importar, transformar e carregar dados no Power BI Desktop utilizando Power Query e outras fontes de dados suportadas.

This module covers how to connect, import, transform, and load data in Power BI Desktop using Power Query and other supported data sources.

🔹 Objetivos do módulo

🔹 Module Objectives

  • Identificar e conectar a diversas fontes de dados
  • Compreender métodos de importação e DirectQuery
  • Aplicar transformações usando Power Query
  • Avaliar qualidade, estrutura e forma dos dados
  • Carregar dados de maneira eficiente para o modelo
  • Identify and connect to various data sources
  • Understand import methods and DirectQuery
  • Apply transformations using Power Query
  • Assess data quality, structure, and shape
  • Load data efficiently into the model
