📥 Load Data into Power BI

Depois de conectar e transformar os dados no Power Query, o próximo passo é carregar os dados no modelo.

After connecting and transforming data in Power Query, the next step is to load the data into the model.

🔹 Métodos de Carga

🔹 Loading Methods

Método Method Descrição Description Uso Ideal Ideal Use
Import Import Dados são carregados no modelo Data is loaded into the model Melhor performance Better performance
DirectQuery DirectQuery Consulta sempre a fonte Always queries the source Dados grandes ou atualizados frequentemente Large or frequently updated data
Dual Dual Pode atuar como Import ou DirectQuery Can act as Import or DirectQuery Modelos compostos Composite models

🔹 Incremental Refresh

🔹 Incremental Refresh

Ideal para grandes volumes de dados. Permite:

Ideal for large volumes of data. Allows:

  • Atualizar apenas partições recentes
  • Refresh only recent partitions
  • Reduzir tempo de atualização
  • Reduce refresh time
  • Otimizar armazenamento
  • Optimize storage

Pré-requisitos:

Prerequisites:

  • Parâmetros RangeStart / RangeEnd
  • RangeStart / RangeEnd parameters
  • Filtro na data de fato
  • Filter on the fact date
  • Dataset publicado em workspace Pro ou Premium
  • Dataset published in Pro or Premium workspace

🔹 Boas Práticas de Carga

🔹 Loading Best Practices

  • Remover colunas inúteis antes de carregar
  • Remove unnecessary columns before loading
  • Evitar tipos de dados textuais pesados
  • Avoid heavy textual data types
  • Conferir cardinalidade das colunas
  • Check column cardinality
  • Revisar dependências de consultas
  • Review query dependencies
  • Evitar colunas calculadas no modelo quando possível
  • Avoid calculated columns in the model when possible
