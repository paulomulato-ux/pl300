⭐ Boas Práticas de Modelagem

⭐ Best Modeling Practices

Estas práticas garantem um modelo limpo, eficiente e fácil de manter.

These practices ensure a clean, efficient, and easy-to-maintain model.

✔ Usar Modelo Estrela

✔ Use Star Schema

  • Tabelas fato no centro
  • Fact tables at the center
  • Dimensões ao redor
  • Dimensions around
  • Evitar snowflake (normalização excessiva)
  • Avoid snowflake (excessive normalization)

✔ Criar Medidas Explícitas

✔ Create Explicit Measures

Evitar medidas automáticas (implícitas). Sempre crie medidas no painel Modeling > New Measure.

Avoid automatic (implicit) measures. Always create measures in the Modeling > New Measure pane.

✔ Nomear Tabelas e Medidas Claramente

✔ Name Tables and Measures Clearly

Exemplos:

Examples:

  • Fato Vendas
  • Fact Sales
  • Dim Produto
  • Dim Product
  • [Total Vendas]
  • [Total Sales]

  • [Active Customers Qty]

✔ Create Display Folders (Display Folders)

✔ Evitar Colunas Calculadas (quando possível)

✔ Avoid Calculated Columns (when possible)

Preferir medidas:

Prefer measures:

  • consume less memory
  • não aumentam tamanho do modelo
  • do not increase model size
