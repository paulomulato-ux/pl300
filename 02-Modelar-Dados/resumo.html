🧩 Resumo – Modelar Dados

🧩 Summary – Data Modeling

Este módulo aborda os princípios essenciais de modelagem dimensional, relações entre tabelas, DAX, desempenho e estruturação de modelos eficientes no Power BI.

This module covers the essential principles of dimensional modeling, relationships between tables, DAX, performance, and structuring efficient models in Power BI.

🎯 Objetivos do módulo

🎯 Module Objectives

  • Construir modelos eficientes baseados em tabelas fato e dimensões
  • Build efficient models based on fact and dimension tables
  • Configurar relacionamentos e cardinalidades
  • Configure relationships and cardinalities
  • Criar medidas com DAX
  • Create measures using DAX
  • Implementar hierarquias
  • Implement hierarchies
  • Controlar direcionalidade de filtros
  • Control filter directionality
  • Otimizar desempenho do modelo
  • Optimize model performance

1. Star Schema

Standard structure recommended by Microsoft:

  • Fact tables → metrics, defined granularity
  • Tabelas dimensão → atributos descritivos
