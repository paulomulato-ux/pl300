📘 Study Material — Certification PL-300: Microsoft Power BI Data Analyst

Este repositório reúne um guia estruturado de estudos para a certificação PL-300, utilizando materiais oficiais da Microsoft, anotações pessoais, exercícios e resumos dos principais tópicos cobrados no exame.

This repository gathers a structured study guide for the PL-300 certification, using official Microsoft materials, personal notes, exercises, and summaries of the main topics covered in the exam.

A princípio foi criado para uso pessoal, mas será continuamente aprimorado para ajudar qualquer pessoa que esteja se preparando para a certificação.

Originally created for personal use, it will be continuously improved to help anyone preparing for the certification.

🎯 Objetivo da Certificação

🎯 Certification Objective

A certificação PL-300 valida habilidades essenciais para atuar como Power BI Data Analyst, incluindo:

The PL-300 certification validates essential skills to work as a Power BI Data Analyst, including:

  • Preparar e transformar dados no Power BI
  • Prepare and transform data in Power BI
  • Modelar dados seguindo boas práticas de BI
  • Model data following BI best practices
  • Criar cálculos com DAX
  • Create calculations with DAX
  • Desenvolver relatórios e dashboards eficazes
  • Develop effective reports and dashboards
  • Aplicar segurança, governança e otimização
  • Apply security, governance, and optimization
  • Publicar, gerenciar e manter soluções analíticas
  • Publish, manage, and maintain analytical solutions
