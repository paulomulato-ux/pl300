📘 Material de Estudo — Certificação PL-300: Microsoft Power BI Data Analyst

Este repositório reúne um guia estruturado de estudos para a certificação PL-300, utilizando materiais oficiais da Microsoft, anotações pessoais, exercícios e resumos dos principais tópicos cobrados no exame.

A princípio foi criado para uso pessoal, mas será continuamente aprimorado para ajudar qualquer pessoa que esteja se preparando para a certificação.

🎯 Objetivo da Certificação

A certificação PL-300 valida habilidades essenciais para atuar como Power BI Data Analyst, incluindo:

  • Preparar e transformar dados no Power BI
  • Modelar dados seguindo boas práticas de BI
  • Criar cálculos com DAX
  • Desenvolver relatórios e dashboards eficazes
  • Aplicar segurança, governança e otimização
  • Publicar, gerenciar e manter soluções analíticas
