🗂️ Gerenciar Workspaces no Power BI

Workspaces são áreas colaborativas onde equipes criam, publicam e gerenciam conteúdos Power BI.

🔹 Tipos de Workspaces

✔ Meu Workspace

  • Uso individual
  • Não recomendado para produção

✔ Workspaces compartilhados

Recomendado para trabalho colaborativo.
Permite: - Publicar relatórios e datasets
- Controlar permissões
- Criar Apps
- Usar pipelines (com Premium)

🔹 Funções do Workspace

Função Permissões
Admin Total controle
Member Edita conteúdo
Contributor Publica, mas não gerencia
Viewer Acessa somente leitura

🔹 Publicar Relatórios

  1. No Power BI Desktop → Publish
  2. Escolher o workspace
  3. Conferir dataset e relatório publicados

🔹 Atualização de Dados

✔ Gateway

Necessário quando a fonte está on-premises.

✔ Agendamentos

  • Até 8x/dia com Pro
  • Até 48x/dia com Premium

🔹 Apps

Os Apps são a forma recomendada de distribuir conteúdo ao usuário final.

Incluem: - Relatórios
- Dashboards
- Dataflows
- Permissões configuráveis
