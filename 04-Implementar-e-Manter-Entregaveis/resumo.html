🛠️ Resumo – Implementar e Manter Entregáveis

Este módulo cobre os tópicos relacionados à implementação, manutenção, segurança e governança de soluções Power BI no serviço online (Power BI Service).

É um dos tópicos mais cobrados na prova PL-300.

🎯 Objetivos do módulo

  • Publicar relatórios e datasets no Power BI Service
  • Organizar conteúdo em workspaces
  • Gerenciar permissões e governança
  • Configurar atualização automática
  • Aplicar segurança Row-Level Security (RLS)
  • Distribuir soluções para usuários finais

🔹 Tópicos Principais

1. Gerenciar Workspaces

  • Funções: Admin, Member, Contributor, Viewer
  • Workspaces Pro x Premium
  • Pipelines de implantação

2. Compartilhamento de Conteúdo

  • Apps
  • Compartilhamento direto
  • Permissões no dataset
  • Uso de Build Permission

3. Governança

  • Data lineage
  • Impact analysis
  • Certificação e promoção de datasets
  • Políticas de acesso

4. Segurança (RLS)

  • Funções de segurança
  • Expressões DAX para filtrar dados
  • Teste e validação de RLS
  • Distribuição para múltiplos usuários

  • RLS: https://learn.microsoft.com/power-bi/enterprise/service-admin-row-level-security
