# 🧪 Guia dos Laboratórios Oficiais – PL-300

Os laboratórios oficiais da certificação PL-300 ajudam a praticar todas as etapas do processo analítico no Power BI: ingestão, transformação, modelagem, visualização, publicação e segurança.

Os labs são fornecidos pela Microsoft através do repositório oficial **MicrosoftLearning**.

* * *

## 📁 Repositório Oficial dos Labs

🔗 https://github.com/MicrosoftLearning/PL-300-Microsoft-Power-BI-Data-Analyst

Nele você encontra:

*   Arquivos **.pbix** iniciais
*   Arquivos finais para referência
*   Arquivos de dados (Excel, CSV, JSON)
*   Instruções passo a passo em PDF ou Markdown

* * *

## 🧭 Estrutura Geral dos Laboratórios

Os labs costumam seguir a seguinte lógica:

### **1\. Preparar Dados**

*   Conectar-se a múltiplas fontes
*   Usar Power Query
*   Aplicar transformações
*   Avaliar qualidade dos dados

### **2\. Modelar Dados**

*   Criar tabelas fato e dimensão
*   Criar relacionamentos
*   Criar colunas e medidas
*   Implementar hierarquias

### **3\. Visualizar e Analisar Dados**

*   Criar relatórios
*   Escolher visualizações
*   Configurar interações
*   Criar KPIs
*   Usar drill-down e drill-through

### **4\. Implementar e Manter Entregáveis**

*   Publicar no Power BI Service
*   Configurar RLS
*   Criar Apps
*   Agendar atualizações

* * *

## 🧑‍💻 Recomendações ao Executar os Labs

*   Execute em ordem para manter consistência
*   Mantenha o Power BI Desktop sempre atualizado
*   Leia atentamente os passos antes de executar
*   Compare com os arquivos finais disponibilizados
*   Refatore as soluções criando suas próprias versões
