# 📌 Resumo – Preparar Dados para Power BI

Este módulo aborda como **conectar, importar, transformar e carregar dados** no Power BI Desktop utilizando Power Query e outras fontes de dados suportadas.

## 🔹 Objetivos do módulo

*   Identificar e conectar a diversas fontes de dados
*   Compreender métodos de importação e DirectQuery
*   Aplicar transformações usando Power Query
*   Avaliar qualidade, estrutura e forma dos dados
*   Carregar dados de maneira eficiente para o modelo

* * *

## 🔹 Tópicos Principais

### 1\. Conectar a fontes de dados

Inclui: - Arquivos (Excel, CSV, TXT, JSON, XML, Parquet)  
\- Bancos de dados (SQL Server, Oracle, PostgreSQL, MySQL, etc.)  
\- Serviços online (SharePoint, OneDrive, APIs, OData)  
\- Microsoft Fabric Lakehouse / Dataverse

* * *

### 2\. Transformar dados com Power Query

Transformações comuns: - Remover linhas/colunas  
\- Alterar tipos de dados  
\- Mesclar e anexar tabelas  
\- Preencher valores  
\- Dividir colunas  
\- Criar colunas condicionais  
\- Agrupamentos e somarizações

* * *

### 3\. Trabalhar com qualidade dos dados

*   Identificar erros
*   Linhas duplicadas
*   Valores nulos
*   Colunas com perfil inconsistente
*   Uso de "Column quality", "Column distribution" e "Column profile"

* * *

### 4\. Carregar dados

*   Import vs DirectQuery
*   Incremental refresh
*   Impactos de performance
*   Gerenciamento de etapas de consulta
*   Boas práticas de carga

* * *
